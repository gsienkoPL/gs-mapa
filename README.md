# GS Mapa — wydania wtyczki QGIS

To repozytorium zawiera wyłącznie **wydania** wtyczki GS Mapa dla QGIS 4.

Treść jest synchronizowana automatycznie z prywatnego repozytorium z kodem
źródłowym (workflow `Sync z repozytorium źródłowego`): pakiet `gs_mapa/`, README,
licencja i archiwa ZIP w zakładce [Releases](../../releases).

Instalacja: pobierz `gs_mapa.zip` z najnowszego wydania i w QGIS wybierz
*Wtyczki → Zarządzaj i instaluj wtyczki → Zainstaluj z pliku ZIP*.
