# Rejestr Urbanistyczny

Wtyczka do QGIS 4 służąca do przeglądania i dodawania warstw z publicznego rejestru urbanistycznego (PMTiles).

## Struktura
- `core/`: Konfiguracja i modele danych.
- `services/`: Logika biznesowa (manifest, operacje na warstwach).
- `ui/`: Interfejs użytkownika (DockWidget).
- `icons/`: Zasoby graficzne.

## Instalacja
1. Skopiuj folder `gs_mapa` do katalogu wtyczek QGIS.
2. Zrestartuj QGIS lub przeładuj wtyczki w Menedżerze Wtyczek.
