about=GS Mapa - a QGIS 4 plugin. One dock with product tabs: the Spatial Planning Register
    (general, local, integrated and voivodeship plans served as PMTiles from gs-mapa.cloud,
    plan information, act documents), OpenStreetMap and BDOT10k basemaps from the
    gs-mapa.cloud server, and a browser of the Register of Spatial Data Sets and Services
    (EZiUDP, GUGiK) that adds the reported WMS, WMTS and WFS services as layers. The APP Files
    tab opens planning-act GPKG/GML files styled with the official APP symbology, validates
    GML against APP 2.0/3.0 (XSD, specification rules, geometry) without a database, converts
    older versions to APP 3.0 and creates new acts with a wizard.

changelog=0.1.1 - Package without scanner configuration
    - The secrets baseline file is no longer shipped; checksums in the APP resources
      carry a sha256: prefix, so the security scan passes with the standard rules.
    0.1.0 - First release in the QGIS plugin repository
    - Plans tab: POG, MPZP, ZPI and PZPW acts from the Spatial Planning Register with the
      official APP symbology, the national register layers, and a plan information tool
      with act documents and links.
    - Whole set: acts of a unit downloaded from the Register index, identifier checks
      before publication (namespace collisions, shared objects, duplicates, acts already
      published), an APP version column and bulk conversion to APP 3.0.
    - APP Files tab: acts opened with the official styles, a read-only file preview, GML
      validation against APP 2.0/3.0 (XSD, specification rules, geometry) from a file or
      from acts already loaded in the project, and conversion of older versions to APP 3.0.
    - APP creator: a wizard for new local, general and integrated plans, a template
      GeoPackage with forms and codelists, cutting the area of a new plan with drawings
      cropped to the new boundary, objects retired instead of deleted.
    - GUGiK tab: search of the EZiUDP catalogue of spatial data sets and services,
      WMS/WMTS/WFS layers, WFS data downloaded to GeoPackage, county data packages.
    - OpenStreetMap and BDOT10k vector basemaps, light and dark theme in the dock and in
      the dialogs.
    - Package: GPL-3.0 LICENSE inside the plugin package, plus a secrets baseline and code
      adjusted to the security scanner of the plugin repository.
